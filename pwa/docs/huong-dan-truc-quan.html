📱 Hướng dẫn trực quan — Ứng dụng Ghi Buổi Tập

Dành cho huấn luyện viên · không cần biết kỹ thuật · làm theo các số đỏ trên hình

Cách đọc hình trong tài liệu này: Mỗi hình là bản vẽ mô phỏng màn hình thật bạn sẽ thấy. Các 1 số đỏ đặt ngay chỗ cần bấm, khớp với danh sách bước bên dưới hình. Màn hình thật có thể hơi khác về màu/vị trí, nhưng tên nút và thứ tự thì giống.

Bạn sẽ đi qua 3 phần (chỉ làm 1 lần)

🗺️ Bức tranh tổng thể — hiểu mình đang làm gì Phần A · Đưa app lên mạng (GitHub Pages) ~15 phút Phần B · Tạo kết nối Google (một lần) ~15 phút Phần C · Kết nối & cài app ra điện thoại ~5 phút ▶ Dùng hằng ngày (sau khi xong) ▶ Xử lý sự cố thường gặp

🗺️ Bức tranh tổng thể

App "Ghi Buổi Tập" là một trang web nhỏ, cài ra màn hình điện thoại để ghi số liệu buổi tập ngay tại phòng gym (kể cả khi mất mạng). Để chạy được, bạn làm 3 việc một lần theo đúng thứ tự:

sơ đồ tổng thể
A Đưa app lên mạng → bạn nhận được một đường link (URL)
⬇
B Tạo kết nối Google → dán "chìa khoá" vào app để nó mở đúng thư mục Drive
⬇
C Cài app ra điện thoại → bấm Kết nối Google + chọn thư mục, xong!
⬇
✓ Hằng ngày: mở biểu tượng app → đã đăng nhập sẵn → ghi số liệu
Làm xong A–B–C một lần. Sau đó mỗi ngày chỉ còn việc cuối (màu xanh).
💡 Cần ai giúp không? Phần A và B hơi nhiều bước nhưng chỉ là bấm theo. Nếu kẹt ở đâu, chụp lại màn hình chỗ đó rồi nhờ người rành máy tính xem giúp — bạn vẫn kiểm soát toàn bộ.
📋 Chuẩn bị trước: một tài khoản Google (Gmail) của bạn (tài khoản chứa thư mục _coach_data), một máy tính có trình duyệt, và khoảng 35 phút ngồi làm một lượt.

B6. Dán "chìa khoá" vào app

Mở file d:\ANATOMY_LIBRARY\pwa\drive-client.js. Gần đầu file có khối DRIVE_CONFIG. Điền vào giữa hai dấu nháy '…':

const DRIVE_CONFIG = {
  clientId:    '123456789-abcdefg.apps.googleusercontent.com',  // ← dán Client ID (B5)
  redirectUri: 'https://phucduhong-coach.github.io/coach/pwa/index.html', // ← đúng link redirect (B4)
  apiKey:      '',   // tuỳ chọn (để '' cũng chạy)
  appId:       '',   // tuỳ chọn (để '' cũng chạy)
};
  1. clientId: dán Client ID đã copy ở B5.
  2. redirectUri: dán đúng link redirect bạn nhập ở B4.
  3. Lưu file. Vì bạn vừa sửa file trong thư mục pwa, hãy tải lại file drive-client.js lên GitHub (làm như A3: Add file → Upload files → chọn đúng file drive-client.js → Commit) để bản trên mạng được cập nhật.
⚙️ apiKey / appId là tuỳ chọn để cửa sổ chọn thư mục (Picker) chạy mượt hơn. Muốn có: vào Credentials → CREATE CREDENTIALS → API key (lấy apiKey) và xem Project number ở trang chủ Cloud (lấy appId). Chưa có cũng không sao, để trống.
✅ Xong Phần B khi: clientId và redirectUri trong DRIVE_CONFIG đã có giá trị thật và đã được tải lại lên GitHub.

▶ Dùng hằng ngày

  1. Mở biểu tượng "Ghi Buổi" trên màn hình chính — đã đăng nhập sẵn, không phải kết nối lại.
  2. Đầu ngày khi còn mạng (ở nhà/quán cà phê): app tự tải lịch tuần về máy.
  3. Ở phòng tập dù mất mạng vẫn ghi số liệu bình thường — lưu ngay trong máy.
  4. Có mạng lại: app tự đồng bộ nhật ký lên Google Drive, bạn không phải bấm gì.
Chưa thấy lịch? Mở máy tính → màn lịch → bấm 📱 Đưa lịch tuần ra điện thoại, rồi mở lại app trên điện thoại (có mạng) để tải về.

▶ Xử lý sự cố thường gặp

  1. App báo hết hạn đăng nhập: bấm Kết nối Google để kết nối lại — dữ liệu đang chờ gửi không mất.
  2. Đăng nhập báo lỗi "redirect_uri_mismatch": link app không khớp ô đã khai ở B4. Mở app, copy đúng link trên thanh địa chỉ, sửa lại Authorized redirect URIs trong Google Cloud cho khớp từng ký tự.
  3. Mất mạng ở phòng tập: cứ ghi bình thường; có mạng lại app tự đồng bộ.
  4. Badge "… đang chờ": bình thường khi mất mạng. Muốn gửi ngay thì bấm đồng bộ thủ công.
  5. Muốn ngắt kết nối / cho mượn máy: bấm Đăng xuất — app thu hồi quyền Google và xoá dữ liệu khách khỏi máy này.
